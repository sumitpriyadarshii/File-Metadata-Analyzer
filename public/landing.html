Architecture

Three focused modules.
One seamless system.

Module 01

Frontend GUI

A pixel-perfect dark dashboard with real-time charts, sortable file tables, and a responsive layout built from pure HTML, CSS, and Vanilla JS.

  • Stat cards with progress indicators
  • SVG donut & bar charts (no libraries)
  • Paginated, searchable file table
  • Scan modal & toast notifications
  • WebGL particle 3D visualization
Module 02

Backend API

An Express.js REST server with structured routes, full CRUD for files and scans, aggregated statistics, and mock-data fallback.

  • GET /api/files — paginated + searchable
  • POST /api/scans — directory scan
  • GET /api/stats/dashboard — analytics
  • DELETE /api/files/:id — cleanup
  • In-memory fallback (no DB required)
Module 03

Database Layer

MongoDB Atlas with Mongoose ODM. Two clean schemas with 200-record seed data and indexed queries for fast analytics.

  • File schema: name, type, size, dates
  • Scan schema: directory, status, counts
  • seed.js — 200 sample file records
  • Indexed on type, size, createdAt
  • Aggregation pipeline for statistics
